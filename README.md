# drmaneli.ir — بازطراحی با GSAP

سایت شخصی دکتر مانلی انصاری مود (متخصص داخلی دام کوچک). پیاده‌سازی سند **Story Flow v1**:
راست‌چین، موبایل‌فرست، آبی + خنثی، و یک روایت اسکرولی (FIP) که با GSAP ScrollTrigger ساخته شده و دقیقاً روی دکمهٔ «شروع ویزیت آنلاین» تمام می‌شود.

خروجی، HTML/CSS/JS ساده است (بدون فریم‌ورک)؛ پوشهٔ `dist/` را روی هر هاست استاتیک (Netlify، GitHub Pages، cPanel…) می‌شود گذاشت.

## اجرا

```bash
npm install
npm run build      # src/ → dist/
npm run dev        # build + سرو روی http://localhost:4173
node tools/shots.mjs /tmp/shots desktop   # اسکرین‌شات از نقاط کلیدی اسکرول (mobile هم دارد)
node tools/qa.mjs                         # تست fallbackها، فرم، منوی موبایل، overflow
```

## ساختار

```
src/pages/*.html        صفحه‌ها (index, about, services, contact, terms)
src/partials/*.html     layout، header، footer، cta، آیکن‌ها
src/assets/css/style.css   سیستم طراحی (توکن‌های رنگ بالای فایل)
src/assets/js/main.js      منو، فرم، و لایهٔ GSAP
tools/build.mjs         سازندهٔ سایت + اطلاعات تماس/مطب‌ها (یک منبع واحد)
tools/cat.mjs           تولید کد‌محور ۴ فریم SVG گربه
dist/                   خروجی قابل انتشار (GSAP و فونت محلی‌اند؛ CDN لازم نیست)
```

اطلاعات تماس، آدرس‌ها و روزهای حضور فقط در `tools/build.mjs` (شیء `site`) تعریف شده و همه‌جا از همان می‌آید.

## انیمیشن‌ها نسبت به سند

| مورد سند | پیاده‌سازی |
|---|---|
| هیرو بدون انیمیشن | هیچ چیزی هنگام لود اجرا نمی‌شود؛ فقط پارالاکس بسیار ملایم عکس (±۴٪، فقط دسکتاپ) |
| ورود ملایم بلوک‌ها | `ScrollTrigger.batch`، fade + slide ‏۰٫۴ثانیه (موبایل ۰٫۳)، stagger ۰٫۰۷ |
| شمارش اعداد | ۳۹ / ۸۰۰+ / ۲۲۵ هنگام ورود به viewport (۰٫۹ثانیه) |
| روایت FIP | ۰–۱۰٪ روز ۱ · ۱۰–۷۵٪ بهبودی + شمارنده تا روز ۸۴ + خاکستری←آبی · ۷۵–۸۵٪ مکث · ۸۵–۱۰۰٪ عقب‌کشیدن دوربین، صدها سیلوئت، ۸۰۰+ و ظهور CTA |
| اسکرول دزدیده نمی‌شود | `position: sticky` معمولی؛ نه pin و نه scroll-jacking |
| تک‌جهته | پیشرفت فقط بیشینه‌اش را نگه می‌دارد؛ اسکرول به بالا ریست نمی‌کند |
| گذار فریم‌ها | opacity + transform (بدون SVG morph) |
| موبایل سبک‌تر | ۳ فریم به‌جای ۴، مسیر کوتاه‌تر (۳۲۰svh)، جمعیت سیلوئت کم‌تر، بدون پارالاکس |
| Fallback | بدون JS / `prefers-reduced-motion` / خرابی بارگذاری GSAP: فقط حالت پایانی (گربهٔ سالم، ۸۰۰+، CTA) و محتوای کامل و خوانا |

## تصمیم‌ها و فرض‌ها (لطفاً بازبینی شود)

- **واتس‌اپ:** شمارهٔ مستقیم ۰۹۳۷۶۳۶۶۱۵۳ فرض شده همان شمارهٔ واتس‌اپ است. فرم رزرو بک‌اند ندارد؛ پیام آماده را در `wa.me` باز می‌کند (و بدون JS هم لینک واتس‌اپ کار می‌کند).
- **نوار هشدار اورژانسی** بالای فرم رزرو و کنار ویزیت آنلاین قرار گرفته (طبق نکتهٔ UX سند).
- **قیمت ویزیت** درج نشده و **نسخهٔ انگلیسی** ساخته نشده (هر دو در «کارهای باز» سند بلاتکلیف بودند).

## کارهای باز قبل از انتشار

1. **عکس‌ها:** فایل‌های `src/assets/img/dr-hero.jpg` (هیرو، ۴:۵) و `dr-portrait.jpg` (درباره من، ۳:۴) را بگذارید؛ build خودکار جای placeholder را می‌گیرد.
2. **متن پاراگراف FIP** (`src/pages/index.html`) پیش‌نویس است و نیاز به تأیید علمی دکتر دارد.
3. **ایلاستریشن گربه** اورجینال و کد‌محور است (`tools/cat.mjs`، بدون ریسک لایسنس). در صورت سفارش طرح حرفه‌ای، ۴ بلوک `.cat-frame` جایگزین می‌شوند و JS تغییری نمی‌خواهد.
4. **لینک ResearchGate:** آدرس دقیق پروفایل را در `tools/build.mjs` (`site.researchgate`) بگذارید.
5. **قوانین و شرایط:** هشت بخش با متن پیش‌نویس خنثی نوشته شده؛ با متن مصوب سایت فعلی جایگزین شود.
6. **لوگو:** فعلاً تک‌حرفی «م» روی آبی؛ تا تصمیم دربارهٔ لوگوی فعلی/جدید.
7. **OG image / favicon نهایی** و آدرس دقیق نقشه‌ها (فعلاً لینک جست‌وجوی گوگل‌مپ).

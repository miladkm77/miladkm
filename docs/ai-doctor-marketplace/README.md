# [نام محصول] — مارکت‌پلیس پزشکی با پیش‌پذیرش هوشمند

اسناد محصول برای MVP یک مارکت‌پلیس پزشکی (شبیه پذیرش۲۴ / نوبت‌دات‌آی‌آر) که در آن:

- بیمار پروفایل سلامت و علائمش را ثبت می‌کند؛
- **ایجنت‌های تخصصی AI** با پروتکل هر رشته سؤالات تکمیلی می‌پرسند؛
- بیمار فقط **تریاژ** می‌بیند (فوریت + تخصص + پزشکان پیشنهادی)؛
- **تشخیص‌های محتمل AI فقط در کارتابل پزشک** نمایش داده می‌شود و پزشک آن را تأیید/ویرایش/رد می‌کند؛
- پزشک می‌تواند با پلن‌های پروموت (برچسب‌دار و بدون اثر بر تریاژ) دیده شود؛
- پنل بیمار، پنل پزشک و پنل ادمین سه اپ جدا هستند.
